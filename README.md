
# Stack Data Structure in C

## About
This repository contains five C programs based on the Stack Data Structure. These programs demonstrate basic stack operations and different applications of stacks.

## Programs Included

### 1. Stack Using Array
Implement a stack using an array with the following operations:
- Push
- Pop
- Peek
- IsEmpty
- IsFull

### 2. Stack Using Linked List
Implement push and pop operations using a linked list.

### 3. Reverse a String Using Stack
A C program to reverse a given string using the stack data structure.

### 4. Next Greater Element
Find the Next Greater Element for each element in an array using a stack.

### 5. Min Stack
Implement a Min Stack with a `getMin()` function that returns the minimum element in O(1) time.

## Concepts Covered
- Stack Data Structure
- LIFO (Last In, First Out)
- Array Implementation
- Linked List Implementation
- Push and Pop Operations
- Stack Applications
- Time Complexity

## Language Used
- C Programming

## Purpose
The purpose of this repository is to practice stack operations and understand how stacks are implemented and used to solve different programming problems.
